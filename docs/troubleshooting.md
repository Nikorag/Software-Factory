# Troubleshooting
- `doctor` reports "no server reachable" for local models: only happens if a route uses `provider: local`. Either start your local model server (and set the route's model id) or route that task to `anthropic`/`haiku`.
- `typescript-eslint does not support TS 7`: TypeScript is pinned to 5.9.x on purpose.
- `pnpm doctor` is a pnpm builtin; use `software-factory doctor`.
- **`npm ci` fails with EPERM on `~/.npm`** (or a tool says "operation not permitted"): the sandbox denied a write. Installs may write package caches; other commands may write only the worktree and temp dirs. Run `pnpm factory project:check <id>` and read `<dataDir>/logs/check/<id>/<step>.log`. If a legitimate tool needs another directory, add it to `factory.sandbox.writeAllow`/`readAllow`.
- **`tsx` fails with `listen EPERM …pipe`:** fixed (Unix sockets in temp dirs are allowed); update to the latest factory.
- **"another factory service is already running":** a live factory service holds `<dataDir>/factory.lock` (its pid and start time are checked, so this is never a reused pid). Stop it with `software-factory shutdown`; a lock from a crashed process is taken over automatically.
- **A PR conflicts with its target branch:** nothing to do; the job goes to `CONFLICT_RESOLUTION` by itself. It only stops (`NEEDS_ATTENTION`) when the two sides genuinely contradict (the message names the files and the question), when the conflict is in a protected path, or after `workflow.max_conflict_resolutions` attempts. Resolve it on the `factory/<KEY>` branch, push, then retry the job.
- **A job is `BLOCKED` with "no implementation prompt":** it was planned in the other planning mode; retry it from requirements analysis.
- **Linear says unauthorised under the LaunchAgent:** the service has no shell environment: create the keychain entry (`security add-generic-password -a "$USER" -s software-factory-linear -w`) and click "Always Allow" on the first prompt.
- **A project job blocks immediately:** read the dashboard job's last error: typically no `commands.test`, the baseline checks failing on the default branch, or (only in `speckit` planning mode) Spec Kit not onboarded (merge the onboarding PR).
- **Dashboard controls are disabled:** open it with `pnpm factory dashboard --open` so the token reaches the page.
