# ADR 0002: Delivery is PR-only; the factory never merges
**Decision (by the owner):** the factory pushes a branch and opens a pull request, watches CI, reports readiness, and waits for a human to merge. **Rationale:** private repos on a free GitHub plan cannot have branch protection, so GitHub cannot enforce required checks; and a human merge is the strongest control over autonomous code. **Consequences:** `mergeMode: pr-only` is the only accepted config value; `GitHubClient` has no merge method and a test asserts none exists; `MERGING` waits (`wait` result) for a human; Linear's "Merging" status is unused. Autonomous merging would need a new ADR, branch protection that GitHub itself enforces, and new code.
