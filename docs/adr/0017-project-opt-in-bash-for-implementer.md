# ADR 0017: Project opt-in to general Bash for the restricted implementer
**Amends ADR 0003** (decision 2: "Agents never run project code directly").

**Context.** The restricted implementer may run only git reads and writes, the factory's check tool, and per-project `agentBashAllow` prefixes. Some projects need more (build tools, generators, scripts) and the only alternative was `agentAccess: unrestricted` (Claude Code auto mode, no factory allow/deny lists at all).

**Decision.** (1) A new per-project boolean, `agentBashAny` (default `false`, set in the project editor or `projects.yaml`), adds a bare `Bash` allow rule to the **restricted implementer only**. It is not a global default and is separate from `agentAccess` and `agentBashAllow` (which is unchanged). (2) Reviewers, the spec-writer and the unrestricted path are unchanged: they never receive a bare `Bash` allow. (3) `ALWAYS_DENY_BASH` stays in force (git push/remote/config/fetch and other branch-moving git commands, gh, curl, wget, ssh, scp, rsync, nc, sudo, su, chmod, chown, launchctl, security, osascript, rm -rf, publish commands, docker, kubectl), as do the protected-path edit denies. A deny rule beats a broad allow in Claude Code (verified, see `src/agents/permissions.ts`). (4) The post-run diff check for protected paths and secrets is unchanged. (5) Bare `Read`, `Write` and `Edit` are still never granted. (6) The implementer prompts stop saying that other code-running commands are refused, but do not claim auto mode.

**Residual risk.** Bash bypasses path rules: with a bare `Bash` allow the agent can read any file the user can read (other projects, `~/.ssh`, the factory database), and can write anywhere through a shell command the deny list does not name, for example `echo x > ~/file` or `python -c`. The deny list is a prefix list and cannot be exhaustive (a different interpreter or an indirect call such as `env curl` or `sh -c` can reach a denied tool). The Claude Code process is still not OS-sandboxed (see SECURITY.md). Enable it only for projects and repositories you trust the agent with.
